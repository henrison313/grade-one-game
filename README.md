# 炫卡闯关游戏 🎮

一款面向一年级儿童的数学学习卡牌收集游戏。

## 在线游玩

🔗 [点击这里开始游戏](https://henrison313.github.io/grade-one-game/)

## 游戏简介

- **炫卡斗士**风格的卡牌收集机制激励学习
- 数学课程基于人教版一年级下学期教材
- 题目难度对标《黄冈小状元作业本》
- 目标用户：~7 岁儿童
- 支持离线游玩

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- React 19 + TypeScript
- Vite
- styled-components
- framer-motion
- react-router-dom
