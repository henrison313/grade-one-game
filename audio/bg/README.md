# 背景音乐资源

## 曲目列表

| 文件 | 用途 | 来源 |
|------|------|------|
| menu-theme.mp3 | 主界面 BGM | Kenney Music Jingles |
| battle-theme.mp3 | 战斗 BGM | Kenney Music Jingles |
| victory-theme.mp3 | 胜利 BGM | Kenney Music Jingles |
| story-theme.mp3 | 剧情 BGM | Kenney Music Jingles |
| collection-theme.mp3 | 卡牌收集册 BGM | Kenney Music Jingles |

## 获取方式

1. 访问 https://kenney.nl/assets/music-jingles
2. 下载 "Music Jingles" 音频包
3. 选择适合的曲目：
   - **menu-theme.mp3**: 选择轻快的菜单音乐，如 "Jingle 01" 或 "Jingle 05"
   - **battle-theme.mp3**: 选择节奏感强的战斗音乐，如 "Jingle 03" 或 "Jingle 07"
   - **victory-theme.mp3**: 选择胜利的庆祝音乐，如 "Jingle 02" 或 "Jingle 06"
   - **story-theme.mp3**: 选择舒缓的剧情音乐，如 "Jingle 04" 或 "Jingle 08"
   - **collection-theme.mp3**: 选择快乐轻快的收集音乐，如 "Jingle 09" 或 "Jingle 10"
4. 将选中的曲目重命名为对应的文件名
5. 放置到此目录

## 临时方案


如果音频文件不存在，游戏会自动使用 Web Audio API 生成的简单 BGM 作为替代。
