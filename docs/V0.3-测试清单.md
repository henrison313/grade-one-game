## 手动测试步骤

1. 启动开发服务器: `npm run dev`
2. 打开首页，验证:
   - BGM 自动播放
   - 点击设置按钮打开设置面板
   - 调节音量生效
3. 进入关卡选择，验证:
   - BGM 继续播放
4. 进入关卡，验证:
   - 剧情 BGM 播放
   - 语音朗读（如启用）
5. 开始答题，验证:
   - 战斗 BGM 播放
   - 答对/答错音效
   - 连击音效
6. 完成关卡，验证:
   - 胜利 BGM 播放
   - 关卡完成音效
