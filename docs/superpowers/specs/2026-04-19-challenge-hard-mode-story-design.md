# 挑战模式和高手模式故事叙事设计

## Context

认识平面图形关卡（level-1-1）目前有三档难度：
- **新手模式**：已有完整故事叙事（魔法森林 → 深海洞穴 → 火焰山谷 → 沙漠遗迹 → 太空堡垒）
- **挑战模式**：故事气泡直接写题目内容，缺乏叙事连贯性
- **高手模式**：同上问题

用户需求：
1. 参照新手模式的故事形式，不把题目内容写到故事气泡里
2. 设计连贯的故事叙事：经历更困难的场景 → 收集更厉害的武器组件 → 再次击败巨力风暴
3. 巨力风暴使出更厉害的绝招进行战斗
4. 收集到巨力风暴更高稀有度的形态炫卡

## 挑战模式设计

### 故事主线

**背景**：巨力风暴在火山深处沉睡，吸收火焰之力正在觉醒。炫蓝闪电需要收集更强的「炫蓝闪电枪」组件，对抗即将苏醒的「巨力风暴火焰形态」。

### 5个场景叙事

| 题序 | 场景名称 | 故事气泡内容 | 武器零件奖励 |
|------|----------|--------------|-------------|
| 1 | **冰封森林** | 巨力风暴沉睡在火山深处！炫蓝闪电带你穿越冰封森林，寻找「圆盘能量核心」唤醒力量！ | 圆盘能量核心 |
| 2 | **深渊火山** | 火山开始喷发！巨力风暴正在觉醒，急需「三角瞄准镜」锁定目标！ | 三角瞄准镜 |
| 3 | **熔岩峡谷** | 巨力风暴吸收了火焰之力，变得更强大！需要「方形能量块」稳定能量！ | 方形能量块 |
| 4 | **云端圣殿** | 巨力风暴火焰形态即将完成！最后的「长方枪身外壳」能保护核心！ | 长方枪身外壳 |
| 5 | **烈焰堡垒** | 炫蓝闪电枪组装完成！巨力风暴火焰形态现身，决战开始！ | 武器完成 |

### 战斗设定

- **炫蓝闪电绝招**：闪电扣杀（配合炫蓝闪电枪发射闪电光束）
- **巨力风暴绝招**：烈焰风暴冲击（火焰效果，巨力风暴图片添加火焰光环）
- **稀有度奖励**：gold（巨力风暴火焰形态炫卡）

## 高手模式设计

### 故事主线

**背景**：巨力风暴火焰形态逃脱后进入宇宙，吸收宇宙能量进化为「终极形态」。炫蓝闪电需要收集最强的「炫蓝雷霆炮」组件，对抗宇宙中最强大的敌人。

### 5个场景叙事

| 题序 | 场景名称 | 故事气泡内容 | 武器零件奖励 |
|------|----------|--------------|-------------|
| 1 | **极光冰川** | 巨力风暴火焰形态逃脱后进入宇宙！穿越极光冰川，收集「雷霆能量环」启动终极武器！ | 雷霆能量环 |
| 2 | **黑洞边缘** | 巨力风暴吸收宇宙能量，正在进化！「雷霆聚焦棱」能聚焦终极力量！ | 雷霆聚焦棱 |
| 3 | **星球核心** | 巨力风暴的力量达到巅峰！「雷霆稳定器」能稳定宇宙能量！ | 雷霆稳定器 |
| 4 | **星云迷雾** | 巨力风暴终极形态即将诞生！「雷霆炮身」是最后的防线！ | 雷霆炮身 |
| 5 | **宇宙圣殿** | 炫蓝雷霆炮组装完成！巨力风暴终极形态现身，终极决战！ | 武器完成 |

### 战斗设定

- **炫蓝闪电绝招**：无限爆裂（配合炫蓝雷霆炮发射宇宙能量光束）
- **巨力风暴绝招**：宇宙风暴毁灭（彩虹效果，巨力风暴图片添加彩虹光芒）
- **稀有度奖励**：rainbow（巨力风暴终极形态炫卡）

## 实现计划

### 需修改的文件

| 文件 | 修改内容 |
|------|----------|
| `src/config/question-story.config.ts` | 更新 MediumStoryConfig 和 HardStoryConfig 的 narratives |
| `src/data/character-ultimates.data.ts` | 添加巨力风暴火焰形态和终极形态的绝招配置 |
| `src/features/battle/battle-scene/battle-scene.component.tsx` | 根据难度切换巨力风暴图片效果（火焰光环/彩虹光芒） |

### 验证步骤

1. 启动开发服务器 `npm run dev`
2. 进入关卡 1-1 选择挑战模式/高手模式
3. 检查故事气泡内容是否为叙事而非题目
4. 完成答题进入战斗画面，检查：
   - 炫蓝闪电绝招名称和武器动画
   - 巨力风暴图片效果（火焰/彩虹）
   - 稀有度显示是否正确（gold/rainbow）
5. 运行 `npm run build` 确认无编译错误
