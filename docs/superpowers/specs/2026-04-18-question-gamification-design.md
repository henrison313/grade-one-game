# 答题系统趣味化设计文档

## 一、背景与目标

### 1.1 问题陈述
当前答题系统"像做题目"，孩子感到厌烦，缺乏游戏性和故事吸引力。

### 1.2 设计目标
- 将题目重新包装为"收集武器零件"的冒险故事
- 增加武器组装进度可视化展示
- 为每个题目设计专属场景背景
- 保持星星获取系统不变（答对每题10颗星星）

### 1.3 实施范围
**试点单元**：【认识平面图形】（第一单元）
- 知识点：圆形、三角形、正方形、长方形
- 题目数量：5道题（每档难度）
- 主角角色：炫蓝闪电（固定）
- 守护者：巨力风暴

---

## 二、核心故事线

### 2.1 整体叙事框架
```
小朋友和炫蓝闪电一起冒险 → 收集图形零件 → 组装炫蓝闪电枪 → 打败巨力风暴
```

### 2.2 三档难度武器体系

| 难度等级 | 目标用户 | 武器名称 | 武器描述 |
|----------|----------|----------|----------|
| **低难度** | 初次学习的小朋友 | 炫蓝光能枪 | 基础武器，能发射光能攻击守护者 |
| **中难度** | 有一定基础的小朋友 | 炫蓝闪电枪 | 升级武器，带瞄准镜和稳定器 |
| **高难度** | 熟练掌握的小朋友 | 炫蓝雷霆炮 | 顶级武器，三合一终极形态 |

## 三、题目设计详解

### 3.1 低难度（炫蓝光能枪）

| 题号 | 图形 | 零件名称 | 场景 | 故事叙事 | 题型 |
|------|------|----------|------|----------|------|
| 1 | 圆形 | 光能核心 | 🌲 森林 | 炫蓝闪电带你来到魔法森林，寻找传说中的"光能核心"。找到圆形就能激活能量！ | 单选 |
| 2 | 三角形 | 光能发射器 | 🌊 海边 | 深海洞穴藏着"光能发射器"。三角形能让闪电精准发射！ | 单选 |
| 3 | 正方形 | 光能护盾 | 🌋 火山 | 火焰山谷里有"光能护盾"。正方形能稳定闪电的能量！ | 单选 |
| 4 | 长方形 | 光能外壳 | 🏜️ 沙漠 | 沙漠遗迹中藏着"光能外壳"。长方形能保护闪电的核心！ | 单选 |
| 5 | 综合 | 光能枪完成 | 🚀 太空 | 在太空堡垒完成最终组装，炫蓝光能枪终于诞生！打败巨力风暴！ | 拖拽配对 |

**题目内容示例**：
- 第1题：下面哪个图形是**圆形**？（4个图形选项：圆形、三角形、正方形、长方形）
- 第2题：找出图中的**三角形**物体（太阳伞、帆船、三角尺的图片）
- 第3题：数一数，图中有几个**正方形**？（1-3个）
- 第4题：下面哪个图形是**长方形**，不是正方形？
- 第5题：把图形拖到对应的位置配对

### 3.2 中难度（炫蓝闪电枪）

| 题号 | 图形 | 零件名称 | 场景 | 故事叙事 | 题型 |
|------|------|----------|------|----------|------|
| 1 | 圆形 | 圆盘能量核心 | 🌲 森林 | 圆形有什么特点？（没有尖尖的角、圆圆的） | 多选 |
| 2 | 三角形 | 三角瞄准镜 | 🌊 海边 | 下面哪两个图形拼起来能变成一个三角形？ | 连线 |
| 3 | 正方形 | 方形能量块 | 🌋 火山 | 正方形和长方形有什么不同？ | 单选 |
| 4 | 长方形 | 长方枪身外壳 | 🏜️ 沙漠 | 用两个三角形可以拼成什么图形？ | 单选 |
| 5 | 综合 | 闪电枪完成 | 🚀 太空 | 在图中圈出所有的圆形和三角形 | 圈画 |

### 3.3 高难度（炫蓝雷霆炮）

| 题号 | 图形 | 零件名称 | 场景 | 故事叙事 | 题型 |
|------|------|----------|------|----------|------|

| 2 | 三角形 | 雷霆聚焦棱 | 🌊 海边 | 一个三角形剪掉一个角，还剩几个角？ | 单选 |
| 3 | 正方形 | 雷霆稳定器 | 🌋 火山 | 正方形对折两次后是什么图形？ | 单选 |
| 4 | 长方形 | 雷霆炮身 | 🏜️ 沙漠 | 用七巧板拼出一个长方形，至少用几块？ | 填空 |
| 5 | 综合 | 雷霆炮完成 | 🚀 太空 | 设计一个图形组合，包含2个圆形+3个三角形+1个正方形 | 拖拽 |

### 4.2 武器组装进度组件

每答对一道题，进度条点亮一个零件：

```
第1题答对前：[?] → [?] → [?] → [?] → [🎯]
第1题答对后：[⚡] → [?] → [?] → [?] → [🎯]  + "光能核心 获得！"
第2题答对后：[⚡] → [⚡] → [?] → [?] → [🎯]  + "光能发射器 获得！"
第3题答对后：[⚡] → [⚡] → [⚡] → [?] → [🎯]  + "光能护盾 获得！"
第4题答对后：[⚡] → [⚡] → [⚡] → [⚡] → [🎯]  + "光能外壳 获得！"
第5题答对后：[⚡] → [⚡] → [⚡] → [⚡] → [🔫]  + "炫蓝光能枪 组装完成！"
```

动画效果：
- 零件图标放大弹出 + 光效闪烁
- 进度条连接线依次点亮
- 最后一个零件组装完成时播放武器完整展示动画

## 六、技术实现方案

### 6.1 新增文件清单

```
src/
├── config/
│   └── question-story.config.ts      # 题目故事叙事配置
│
├── features/
│   └── question-scene/               # 题目场景化渲染
│       ├── question-scene.component.tsx
│       ├── weapon-progress.component.tsx
│       ├── scene-background.component.tsx
│       └── question-story.component.tsx
│
├── data/
│   └── levels/
│       └── level-1-1-enhanced.data.ts  # 增强版关卡数据（三档难度）
│
└── types/
    └── difficulty.types.ts           # 难度等级类型定义
```

### 6.2 数据结构扩展

```typescript
// 新增难度类型
interface DifficultyLevel {
  id: 'easy' | 'medium' | 'hard';
  name: string;
  weaponName: string;
  weaponParts: WeaponPart[];
  settings: DifficultySettings;
}

// 武器零件
interface WeaponPart {
  id: string;
  name: string;
  shapeType: 'circle' | 'triangle' | 'square' | 'rectangle';
  iconImage: string;
  collected: boolean;
}

// 增强版题目
interface EnhancedQuestion extends Question {
  storyNarrative: string;      // 故事叙事
  sceneBackground: string;     // 场景背景图片路径
  weaponPartReward: WeaponPart; // 答对奖励的零件
}
```

### 6.3 复用现有组件

| 现有组件 | 复用方式 |
|----------|----------|
| `ChoiceQuestion` | 选项渲染逻辑不变，增加故事包装层 |
| `AnswerFeedback` | 增加零件获得动画 |
| `Shape` | 显示几何图形选项 |
| `StarDisplay` | 星星进度显示不变 |
| `UltimateAnimation` | 武器组装完成时播放类似特效 |
