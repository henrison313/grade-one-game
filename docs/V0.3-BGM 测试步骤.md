# V0.3 BGM 切换测试步骤

## 测试目标
验证场景切换时 BGM 是否正确切换（停止前一个，播放新的）

## 测试步骤

### 步骤 1：首页加载
1. 打开 http://localhost:3000/
2. 点击页面任意位置（解锁音频）
3. **预期**：
   - 控制台日志：`playBGM called: menu`
   - 控制台日志：`BGM menu started playing successfully`
   - 只播放一次 menu BGM

### 步骤 2：进入关卡选择
1. 点击"开始冒险"
2. 导航到 `/levels`
3. **预期**：
   - 控制台日志：`playBGM called: menu, current: menu`
   - 控制台日志：`BGM menu already playing`
   - 没有重复播放

### 步骤 3：进入关卡剧情
1. 选择一个关卡，点击开始
2. 导航到 `/level/:id/intro`
3. **预期**：
   - 控制台日志：`playBGM called: story, current: menu`
   - 控制台日志：`Loading BGM: /audio/bg/story-theme.mp3`
   - 控制台日志：`BGM story started playing successfully`
   - **menu BGM 停止**，只有 story BGM 播放

### 步骤 4：进入答题
1. 点击剧情"开始挑战"
2. 导航到 `/level/:id/play`
3. **预期**：
   - 控制台日志：`playBGM called: battle, current: story`
   - 控制台日志：`Loading BGM: /audio/bg/battle-theme.mp3`
   - 控制台日志：`BGM battle started playing successfully`
   - **story BGM 停止**，只有 battle BGM 播放

### 步骤 5：完成关卡
1. 完成所有题目
2. 导航到 `/level/:id/complete`
3. **预期**：
   - 控制台日志：`playBGM called: victory, current: battle`
   - 控制台日志：`Loading BGM: /audio/bg/victory-theme.mp3`
   - 控制台日志：`BGM victory started playing successfully`
   - **battle BGM 停止**，只有 victory BGM 播放

### 步骤 6：返回关卡选择
1. 点击"返回"或"下一关"
2. 导航回 `/levels`
3. **预期**：
   - 控制台日志：`playBGM called: menu, current: victory`
   - 控制台日志：`Loading BGM: /audio/bg/menu-theme.mp3`
   - 控制台日志：`BGM menu started playing successfully`
   - **victory BGM 停止**，只有 menu BGM 播放

## 关键验证点

### 每次切换检查：
- [ ] 前一场景 BGM 是否停止（`currentBGMType` 应该被清空）
- [ ] 新场景 BGM 是否播放
- [ ] 没有多个 BGM 同时播放

### 控制台日志检查：
- [ ] 每个 BGM 类型只出现一次 `started playing successfully`
- [ ] 没有出现 `x2` 标记
- [ ] `current:` 字段显示正确的前一个 BGM 类型

## 常见错误日志

### 错误 1：多个 BGM 同时播放
```
[Log] BGM story started playing successfully
[Log] BGM battle started playing successfully  // 故事没停
```

### 错误 2：重复播放同类型
```
[Log] BGM menu started playing successfully
[Log] BGM menu started playing successfully  // 重复
```

### 错误 3：状态未清空
```
[Log] playBGM called: battle, current: story  // 正确
[Log] playBGM called: battle, current: story  // 又调用一次
```
