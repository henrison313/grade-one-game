添加 2 个隐藏关卡和 8 个角色重设计，丰富游戏内容

| 类别 | 内容 | 数量 |

| 隐藏关卡 | H1 超炫电光王、H2 炫蓝雷霆王 | 2 个 |

**3-4 天**

## 二、任务分解

### Task 1: 隐藏关卡数据配置
**优先级**: P0
**预计时间**: 4 小时

#### 1.1 创建隐藏关卡数据结构
**文件**: `src/data/hidden-levels.data.ts`（新建）

```typescript
interface HiddenLevel {
  id: string;
  name: string;
  guardian: Character;
  difficulty: number;
  starThreshold: number;
  unlockConditions: UnlockCondition[];
  logic: 'AND' | 'OR';
  questions: Question[];
  story: StorySegment[];
  reward: {
    card: Card;
    skill?: Skill;
  };
}
```

#### 1.2 创建 H1 关卡题目数据
**文件**: `src/data/levels/level-h1.data.ts`（新建）

**内容**: 5 题递进式数位理解挑战
- 题 1: 用 3 个圆片摆数（拖拽）
- 题 2: 最大最小数（滑动）
- 题 3: 规律发现（填空）
- 题 4: 逆向思维（选择）
- 题 5: 挑战极限（限时 30 秒填写）

#### 1.3 创建 H2 关卡题目数据
**文件**: `src/data/levels/level-h2.data.ts`（新建）

**内容**: 4 题跨单元综合挑战
- 题 1: 图形 + 计算（七巧板拼 8 + 减法）
- 题 2: 人民币 + 退位减（购物最优方案）
- 题 3: 规律 + 应用（找规律编题）
- 题 4: 开放创作（设计题目）

**验收标准**:
- [ ] 隐藏关卡数据结构完整
- [ ] H1 和 H2 题目数据符合 PRD
- [ ] 解锁条件配置正确（AND 逻辑）

**文件**: `src/services/hidden-level-unlock.service.ts`（新建）

```typescript
interface UnlockCondition {
  type: 'levels_completed' | 'stars_collected' | 'accuracy';
  targetLevels?: string[];
  minStars?: number;
  minAccuracy?: number;
}

class HiddenLevelUnlockService {
  checkUnlock(levelId: string): boolean;
  getUnlockConditions(levelId: string): UnlockCondition[];
  watchProgress(): Observable<UnlockProgress>;
}
```
