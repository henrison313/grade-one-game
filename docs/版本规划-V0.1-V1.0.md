## 产品概述

**项目名称**: 炫卡斗士：数学大冒险

**核心定位**: 面向 6-8 岁一年级儿童的数学学习卡牌收集游戏

**核心价值**:
- 游戏化学习：将数学练习转化为卡牌收集游戏
- 难度递进：21 关卡按人教版教材单元设计
- 即时反馈：星星积分视觉化学习成果
- 收集激励：21 个独特角色炫卡收集册

**目标用户**:
- 主要用户：6-8 岁小学一年级学生
- 次要用户：家长（监督学习进度）、教师（课堂教学辅助）

**技术栈**: React 19 + Vite + TypeScript + styled-components + Framer Motion
