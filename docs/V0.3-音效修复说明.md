# V0.3 音效系统修复说明

## 问题原因

`public/audio/` 目录不存在，导致所有音频文件都无法加载：
- 背景音（BGM）无法播放
- 音效（正确/错误/点击等）无法播放
- 只有剧情语音能工作（使用 Web Speech API，不需要音频文件）

## 解决方案

修改 `sound.service.ts`，添加**音频生成回退机制**：

### 1. 音频文件存在检测
```typescript
private async checkAudioFileExists(path: string): Promise<boolean>
```
首次播放前检查音频文件是否存在，结果缓存避免重复检查。

### 2. Web Audio API 生成音效
当音频文件不存在时，使用 Web Audio API 实时生成音效：

| 音效类型 | 生成方式 |
|---------|---------|
| correct | 上升三音阶 C5-E5-G5 |
| wrong | 下降双音 Eb4-C4 |
| click | 单音 800Hz |
| victory/level-complete | 胜利旋律 |
| card-reveal | 上升六音阶 |
| summon | 魔法召唤音效 |
| combo-1/5/10 | 递增强度音 |
| ultimate-* | 根据稀有度生成不同音效 |

### 3. BGM 生成回退
当 BGM 音频文件不存在时，生成简单节拍作为占位：
- menu: 440Hz 节拍
- battle: 330Hz 节拍
- victory: 523Hz 节拍
- story: 392Hz 节拍

## 目录结构

```
public/audio/
├── bg/
│   ├── menu-theme.mp3      # 如存在则使用，否则生成
│   ├── battle-theme.mp3
│   ├── victory-theme.mp3
│   └── story-theme.mp3
├── sfx/
│   ├── correct.mp3         # 如存在则使用，否则生成
│   ├── wrong.mp3
│   └── ... (20个音效文件)
└── ultimate/
    ├── bronze.mp3          # 如存在则使用，否则生成
    └── ... (5个绝招音效)
```

## 优先级逻辑

1. **音频文件存在** → 使用音频文件播放
2. **音频文件不存在** → 使用 Web Audio API 生成
3. **音频文件播放失败** → 回退到生成音效

## 如何添加真实音频文件

当获取到真实音频文件后，只需放入对应目录即可自动使用：

```bash
# 示例：添加 BGM
cp menu-music.mp3 public/audio/bg/menu-theme.mp3

# 示例：添加音效
cp correct.mp3 public/audio/sfx/correct.mp3
```

无需修改代码，系统会自动检测并使用真实音频文件。

## 测试验证

1. 打开首页 → 应听到背景节拍声
2. 点击按钮 → 应听到点击音效
3. 进入关卡答题 → 应听到正确/错误音效
4. 完成关卡 → 应听到胜利音效
5. 查看设置面板 → 音量调节应实时生效

## 技术细节

- 音频检测使用 `fetch HEAD` 请求
- 检测结果缓存到 `Map` 避免重复请求
- 生成音效使用 `OscillatorNode` 和 `GainNode`
- BGM 使用 `setInterval` 创建循环节拍
- 所有生成音效都遵循设置的音量
